# Hindu Corpus

Source corpus and RAG-ready data for research across Indian traditional knowledge systems and modern human-biology reference data.

## Scope

- Indian primary and traditional texts
- Sanskrit linguistic and morphological data
- Ayurveda, Yoga, Tantra, Purana, Veda, Upanishad and related traditions
- Human anatomy and cell ontologies
- Human Reference Atlas / Common Coordinate Framework (HRA/CCF)
- Provenance, manifests and licensing metadata

## Storage model

Small text, metadata, schemas and reproducibility scripts belong in this repository.

Large corpus archives are distributed separately through GitHub Actions artifacts/releases because GitHub's normal Git file limits are not suitable for multi-hundred-MB and GB source archives.

## Research principle

This corpus is designed for source-grounded cross-domain investigation. Traditional concepts and modern biological constructs must remain distinct. Candidate relationships are represented as hypotheses or documented correspondences with provenance, chronology, supporting evidence, counter-evidence and uncertainty; they are not encoded as automatic equivalences.

## Sources

Source-specific attribution and license information must be preserved with every dataset. Check each dataset's manifest/license before redistribution or commercial use.
